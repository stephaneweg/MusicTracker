**KEY lessons from Ch.11 (Final Synopsis) — the weak link is NOT the algorithm, it's mapping + EVALUATION:**
- "Compose in the style of X" = **style imitation**, the dominant paradigm (corpus OR rule/constraint based). The user's goal is mainstream.
- ⚠️ **Over-smoothing trap (11.4):** mapping algorithm output onto "a few pitches melodious in all combinations" gives a pleasant texture but "the structure-forming algorithm becomes exchangeable" → this is exactly our over-snapping to scale/chord-tones = pretty but generic/characterless. Dose the constraint per style; don't lisser everything.
- 🔑 **Objective EVALUATION is THE neglected key (11.5, Pearce & Wiggins):** "One cannot judge the enterprise a success simply because the network creates novel output." We generate lots, select/score almost nothing objectively.
- Constraints describe a CLASS (11.6): too tight → recopies corpus; too loose → off-style.

**PROPOSED improvements (book-grounded), by value:** (a) **a musical "critic"/evaluator** = generalize the genetic `Fitness` into an objective scorer (scale/style fit, contour, tension/release, density, cadence, voice-leading) that SELECTS/REJECTS generated variations — reusable everywhere, THE #1 lever; (b) **constraint-based harmony/voice-leading** (Ch10); (c) **generative grammar for phrase/form** (antecedent/consequent, motivic development, Ch4); plus tune the mapping (less over-snapping). The critic is valuable regardless of the catalog-vs-full-algo choice.
