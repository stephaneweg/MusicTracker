Corpus consolidated at repo `midi\vivaldi_full\` (from `midi\vivaldi\`: Four Seasons movts spring/summer/winter + rv540, arias, Gloria RV589 from botproductions.com, + 51 from classicalmidi.co.uk). **Results (and the Vivaldi≠Bach contrasts):**
- **Texture**: LARGE ENSEMBLE — avg ~6 voices, up to 15 (orchestral concerti/sacred), vs Bach's 2–4. Voice-entry stagger ~26 qtr (ritornello entries).
- **Rhythm**: 8th 30% / 16th 29% / 32nd 19% / 8th-triplet 6% / dotted-8th 5% (full corpus). 32nd validity checked via analyze_trills.ps1 after the user asked if 32nds are trills/tremolos — AND re-run on a CLEAN subset (`midi\vivaldi_seasons`: the user's curated Four Seasons + RV540, 12 files, single source). Result:
  - FULL (heterogeneous) corpus: 32nds = 29% real figuration / 11% tremolo / 10% trill / **49% isolated**; detached 18%.
  - CLEAN subset: 32nds = **56% real figuration** (≈ Bach 57-59%) / **22% tremolo** / 10% trill / **13% isolated**; detached **5%**; 16th 38% / 32nd 27% / 8th 24%; unison(repeated) 38%.
  → The user's artifact suspicion was RIGHT (isolated 49→13, detached 18→5 = classicalmidi quantisation noise), but cleaning REVEALS the real signal: Vivaldi's 32nd VIRTUOSITY is genuine (56% real runs, like Bach), AND a strong distinctive **TREMOLO / repeated-note motor** (22% of 32nds, vs Bach 0%; explains the high unison/repeated-note %). Use the clean subset for a Vivaldi style, not the classicalmidi bulk.
- **Melody**: **repeated notes ~31%** (unison) — the Vivaldi REPEATED-NOTE MOTOR (driving ostinati / string tremolo / ritornello energy), vs Bach ~5%. Step 34% / leap 35%. Run length 1.6. **Motif repetition 72%** — very SEQUENTIAL (ritornello sequences, circle-of-fifths).
- **Dynamics / rests**: **silence 35%, detached 18%** (vs Bach ~13%/4%) — the CONCERTO RITORNELLO principle: tutti/solo alternation (instruments rest while others play) + detached articulation. Rest values dominated by 32nd-gaps (fast detached) + on-beat breaths.
- **Harmony**: FUNCTIONAL like Bach — **V→I 32%, iv→I 20%, ii→V→I, i→iv→I**; closes v→I 22%; clear T-S-D-T flow; secondary dominants (II→v). 46 major / 34 minor. Harmonic rhythm **~2.3 changes/bar**.
- **Counterpoint**: BASS more STEPWISE (54% vs Bach 39% — a walking/scalar continuo). Outer voices 3rds 25% + 6ths 13% = 38% imperfect, BUT **contrary motion only 26%** (vs Bach 35%) — more PARALLEL 3rds/6ths (Italian string doubling, less contrapuntal independence). Suspensions ~4%.

**THE emergent Vivaldi signature vs Bach**: (1) big orchestral ensemble; (2) repeated-note motor drive; (3) brilliant 32nd virtuosity; (4) ritornello tutti/solo ALTERNATION (lots of rests, contrasting forces); (5) more PARALLEL motion / string doubling (less independent counterpoint than Bach); (6) walking stepwise bass; (7) intensely sequential. Harmony itself is similar baroque functional language.

**IMPLEMENTED (2026-06-15) — Vivaldi style (Composer.cs, style index 2):** distinct from Bach via `cfg.parallel` + `cfg.motor`:
- **Parallel 3rds/6ths doubling** (`ParallelVoice`): extra voices shadow the lead a 3rd/6th below (snapped to chord tones on strong beats) instead of independent counterpoint/canon — Italian string writing. Verified 89% 6ths, 90% parallel/similar motion.
- **Repeated-note MOTOR bass** (`GenerateFiguredBass(..., motor:true)`): driving repeated eighths on the chord root (last one steps toward the next root). Verified 8 notes/bar, 60% repeated.
- **VIRTUOSITY dial** (the user asked to control the amount of 32nds): new `virtuosity` param to Compose (dialog "Virtuosité" combo Auto/Aucune/Légère/Moyenne/Élevée → -1/0/1/2/3) scales `DevelopMotif` diminution rate. Verified 0→0% / 1→19% / 2→41% / 3→66% of lead notes are 32nds. Auto = LIGHT (1, ~19%, "not too many"); florid profile → 3.

**`VivaldiComposer : ComposerV2Base`** (`Engine/ComposerV2/VivaldiComposer.cs`, 2026-06-17) — RITORNELLO concerto allegro, 4 parts: solo violin (40) / ripieno strings (48) / harpsichord (6) / continuo bass (43); 4/4, bpm 116-131; tonal major/minor; tonic from naturals. Form R1(home)–S1–R2(dominant +7)–S2–R3(relative: minor +3 / major +9)–S3–R4(home)–cadence. `Ritornello(theme,plan,startSlice,offset,full)`: solo theme (GenerateLine over I-IV-V-I, transposed by `offset` semitones) + **ripieno parallel 3rd/6th below** (`NearestChordTone(p-4,…)`, Italian doubling) + `MotorBass` (8 driving eighths on the root, last steps to next) + `HarpChords` (broken eighths). `SoloEpisode`: solo violin **continuous 16th arpeggio wave** (`Ladder` up-then-down) over a circle-of-fifths sequence (vi-ii-V-I), **ripieno TACET** (the solo/tutti contrast) + walking continuo + harp. `FinalCadence` = V→tutti Picardy tonic. Verified per-voice-per-bar: RIP fills ritornello bars + rests in episodes; SOLO 6-7 notes (theme) vs 16 (figuration); BASS motor-8 in tutti / walk-4 in solo.
