**Goal (user, 2026-06-19):** total flatten of the composition engine for readability/maintainability. Delete "Créer un morceau auto" + all previous engines (ComposerV2Base/wrappers, Timeline.GhibliComposer V1). Replace with:
- **Orchestrateur** (`Engine/Timeline/Orchestrateur.cs`, style-agnostic, 1 per model): owns FORMS (sonate/ballade/rondeau/ABACAD/ABCD/arc…) + HUMEUR (Mood enum); builds charpente + sections; calls the emitter to fill them; assembles the editable ComposedArrangement.
- **ComposerV3 emitters** (`Engine/ComposerV3/`): `BaseComposerV3` (generic) + `BachComposerV3`/`VivaldiComposerV3`/`GhibliComposerV3` (+ `BachClavierComposerV3` for now). Own model load + usage; expose STYLES (Bach: prélude/fugue/allemande…); emit chords/notes/chord-motif per **style+mood+section** via `GetChords` / `GetNote(staff)` / `GetChordMotif`.
- **UI selection** = Modèle (→ composer via filename) · Forme · Style · Humeur + tonalité/tempo/tailles. Editing routes through Orchestrateur/ArrangementEngine, never the V1.
