Feature (2026-06-14): each timeline track header has a **♫ "Partition"** button that renders the track's notes as standard notation in the bottom editor area, with a yellow cursor that follows playback.

**MAJOR REWRITE 2026-06-14 (multi-staff + Bravura + MuseScore spacing):** `ScoreView.Configure(IList<TrackScore> tracks, beatsPerBar)` renders N tracks as N stacked staves sharing ONE horizontal time axis (columns) + one cursor spanning all. **Trills/trémolos REMOVED** (fast runs just render as beamed notes). **GrandStaff REMOVED** — each track = ONE staff; clef = explicit-from-import (`TimelineTrack.Clef`) ?? instrument (`ScoreClef.ForTrack` has `out bool autoClef`) ?? `ScoreBuilder.ClefByRange` (avg written pitch ≥ middle C → treble else bass). Per-staff own clef + derived key (transpose) + spelling; `contentLeftX` reserves the MAX armure width so staves align. **Spacing** = MuseScore-style power law per onset column: `SpaceFor(beats)=SpaceMin+SpaceStretch·beats^0.6`; cursor `BeatToX` interpolates between columns. **Glyphs = Bravura SMuFL** (`MusicTracker/Fonts/Bravura.otf` Resource; built from char codes `Smufl(0xExxx)` since PUA chars are invisible in source) — clefs/accidentals/rests/key-sig/time-sig; drawn heads/stems/beams/flags. `SetCursorBeat` does a PAGE-TURN scroll: when the cursor comes within one measure (`beatsPerBar·SpaceFor(1)`, capped at 40% of the viewport) of the right edge (or scrolls off the left), it jumps so the cursor sits ~30px from the left, revealing the upcoming measures. In **TimelineScreen** the header has a **♫ CheckBox** (not a button); `scoreTracks` HashSet → `RefreshScore()` builds a `TrackScore` per checked track and configures the multi-staff view; cleared on load/import/track-delete. The single-staff history below remains accurate for the drawing internals (beaming, within-measure accidentals, key detection, etc.) but the layout/glyph/trill/grand-staff bits are superseded by this paragraph.

**Files:**
- `Engine/Score/ScoreModel.cs` — `ScoreNote {StartBeat, Beats, Midi(sounding)}`, `TrackScore {Notes, TotalBeats, Clef, Transpose, IsDrum}`, `ScoreClefKind {Treble,Bass,Alto,Tenor,GrandStaff}`, `ScoreClef.ForTrack(gmProgram, isDrum, out clef, out transpose)`, `ScoreBuilder.Build(project, track, resolveRiff)`. ScoreBuilder MIRRORS `TimelinePlayer`'s flatten (PlaceItem/PlaceLeaf/RiffForModule: repeats expanded, PlayRiff→RiffById, Pattern→PatternGenerator.Generate, Drum→DrumPattern.Generate) so the score matches playback; emits absolute-beat notes (midi = n.Note+12); **starts AND durations are snapped to 1/8 of a beat** (`DisplayQuantum=0.125`, `SnapQ`) for clean notation/alignment — display-only, the riff/playback data stays precise.
- `Controls/Score/ScoreView.cs` — code-only `UserControl` (ScrollViewer→Canvas, no XAML). `Configure(TrackScore, beatsPerBar=4)` draws; `SetCursorBeat(double)` sweeps + auto-scrolls the cursor. **Horizontal layout is VALUE-BASED, not linear in beats** (`BuildLayout`/`BeatToX`): time points = note starts/ends + bar boundaries; each segment's width = `CellWidth(seg)` chosen by the note VALUE class (`BaseVal`/`BaseWidth`: ronde 110…triple-croche 16), and a DOTTED note takes the SAME width as its base (CellWidth strips the dot). Each bar line adds a `MeasurePad`(16) of room after it so notes don't hug the barline. `BeatToX(beat)` is a piecewise-linear lookup over the time-point map; ALL positioning (notes, rests, trill marks, bar lines via `barNatX`, and the playback cursor) goes through it — so the cursor tracks the non-linear spacing correctly. Consts: StaffGap=9. Pitch→staff via diatonic step (PcStep/PcSharp tables); bottom-line steps: Treble 30(mi4), Bass 18(sol2), Alto 24(fa3), Tenor 22(ré3). Grand staff = treble (midi≥60) + bass (<60). Renders staff lines, clef (Unicode 𝄞/𝄢/𝄡 via TextBlock FontFamily "Segoe UI Symbol,Cambria Math,Segoe UI Historic" + WPF fallback), 4/4 time sig, bar lines every beatsPerBar, chords (notes grouped by start quantised to 1/48) with one stem + flags, ledger lines, ♯ accidentals.

**Clef + transposition (ScoreClef.ForTrack, by GM program):** Violin(40)→treble; Viola(41)→alto/ut; Cello(42)/Contrabass(43)/Bassoon(70)/Trombone(57)/Tuba(58)/basses(32-39)→bass; Piano(0-7)/Harp(46)→grand staff; flute/oboe/etc→treble. **Transposing (written = sounding + N semitones):** Clarinet/Trumpet/Soprano-sax si♭ +2, Cor anglais/Cor en fa +7, Alto sax mi♭ +9, Tenor sax si♭ +14, Bari sax mi♭ +21. Octave-transposing instruments (guitar/contrabass/piccolo) left at concert pitch (clef only). Drums → bass clef, no transpose.

**MuseScore-style spacing (2026-06-14):** layout is COLUMN-based (one X per distinct onset beat across staves + bar boundaries), not beat-cells. Each column's width = `SpaceFor(durationToNextColumn) = SpaceMin + SpaceStretch·beats^0.6` (power-law → a whole note ~1.8× a quarter, not 4×); accidental columns reserve `AccReserve` on the left; `MeasurePad` after each bar line. `axBeat`/`axX` = column beats→x (also the cursor anchors); `SlotX` looks up the column; `BeatToX` interpolates → the cursor glides smoothly between musically-spaced note positions. ScoreView is a reusable `UserControl` taking a `TrackScore` (clef/key/transpose/notes) + beatsPerBar. (Chord-generator `PatternGeneratorModule` + `DrumPatternModule` are included via `ScoreBuilder.RiffForModule`.) `MeasurePad` after each bar line. **Beaming** (`DrawBeamGroup`): consecutive contiguous same-measure beamable notes (Flags≥1) are joined under one beam (primary + secondary 16th/32nd beams with stubs); a lone short note keeps its flag (`DrawSingleNote`). `DrawHeads`/`DrawStemFlags` split out so beams override flags. Isolated croche/double/triple flags are a CURVED hook (`BuildFlag`, Bézier path), not a polygon. Cells widen by `AccReserve` per note that carries an accidental (`cellW[]` variable per cell) so the ♯/♭/♮ has room; accidentals drawn larger/bold (StaffGap*2.5).
