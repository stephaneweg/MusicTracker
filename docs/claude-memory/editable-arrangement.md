Goal (user, 2026-06-16): after auto-composing, be able to **edit the chords and the theme by hand and have it propagate** — editing the theme re-derives ré-expo/dev/recap (transpose/transform per each bar's chord degrees) and recomputes the counter-melody; editing a chord re-derives bass + accompaniment. Decided: an editable **chord lane above the timeline** (label→textbox like the tempo lane), and **derived sections are LOCKED (always regenerated)** — you only edit the theme + the chords. See [[hisaishi-ghibli-analysis]] for the GhibliComposer this is built around.
